# SDU Data & Intelligence Lab

Minimal GitHub Pages starter for the Data & Intelligence Lab at the University of Southern Denmark.

Current URL:
https://ac-hm.github.io/sdu-data-intelligence-lab/

This is a GitHub project site, so the default URL includes the account name and repository name.
If you want a URL without your GitHub username, the usual option is a custom domain.

What is included:
- a one-page layout with a simple research, publications, people, and join structure
- placeholder logo and hero image assets
- plain HTML and CSS so it can be hosted directly on GitHub Pages

Replace the placeholders:
- assets/brand-mark.svg is the temporary logo mark
- assets/hero-placeholder.svg is the hero illustration

Publish notes:
- push changes to main when you update the site
- GitHub Pages is already configured for this repository
- if you later add a custom domain, set it in the repository Pages settings

# Publication data

Each member maintains one JSON file in this folder. The personal Publications
page reads that member's file, and the lab Publications page combines all
member files into one year-by-year archive.

Keep the fields `year`, `title`, `authors`, `venue`, and `url` for each record.
The `url` should point to the official publication record or DOI.

Serkan's file is refreshed automatically from the selected-publications list
on his personal homepage by the scheduled GitHub Action.
